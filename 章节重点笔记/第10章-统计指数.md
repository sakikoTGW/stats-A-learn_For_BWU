## 一、概念

| | 含义 |
|---|------|
| **广义** | 一切相对数 |
| **狭义** | 不能直接加总对比的复杂现象的综合**动态相对数** |

**作用**（PPT）：① 综合反映事物变动的**方向**和**水平** ② 宏观经济指示器；反映居民生活变化的指标（如 **CPI**）。

**分类**：数量指标指数 / 质量指标指数；个体指数 / 总指数。

---

## 二、个体指数

\[
I_q = \frac{q_1}{q_0}, \quad I_p = \frac{p_1}{p_0}
\]

**个体指数**：反映**单一项目**的变动（一种商品的价格或销量）。

**课件例题（商场三商品）**：

| 商品 | 销售量 \(I_q\) | 价格 \(I_p\) |
|------|----------------|--------------|
| 铅笔 400→600，0.8→0.9 | **150%**（+50%） | **112.5%**（+12.5%） |
| 围巾 120→105，25→24 | **87.5%**（−12.5%） | **96%**（−4%） |
| 帽子 80→100，20→18 | **125%**（+25%） | **90%**（−10%） |

---

## 三、综合指数与同度量因素

**为什么需要同度量因素**：不同商品单位不可直接加总；用 \(pq\) 把 q、p 化为可加的**销售额**。

**编制原则（必背）**：

| 指数类型 | 同度量因素固定在 | 指数名 |
|----------|------------------|--------|
| **数量指标指数** | **基期**价格 \(p_0\) | **拉氏**物量指数 |
| **质量指标指数** | **报告期**销售量 \(q_1\) | **派氏**价格指数 |

**思想**：固定一个因素，测另一个因素的变动（假定法）。

### 拉氏 vs 派氏（公式逻辑）

**拉氏数量指数**（测销量综合变动，价固定在基期）：

\[
L_q = \frac{\sum p_0 q_1}{\sum p_0 q_0}
\]

分子−分母差额 → 因**销售量**变动引起的销售额变动（课后 D）。

**派氏价格指数**（测价格综合变动，量固定在报告期）：

\[
P_p = \frac{\sum p_1 q_1}{\sum p_0 q_1}
\]

**派氏物量、拉氏价格** 同理，权数时期对调。

**经济规律（正常）**：**拉氏 > 派氏**（C）；派氏 110% 则拉氏 **>110%**（C）。

**其他**：马埃（基报告期数量平均权）；**理想指数** = 拉氏与派氏的几何平均（费雪）。

### 指数意义辨析（课后）

| 公式经济意义 | 答案 |
|--------------|------|
| \(\sum p_0 q_1 - \sum p_0 q_0\) | **销售量**引起销售额变动 D |
| \(\sum p_1 q_1 - \sum p_0 q_1\) | **价格**引起销售额变动 |
| 拉氏物量指数 \(\sum p_0 q_1/\sum p_0 q_0\) | 销售量变动程度及销售额影响 **CE** |

## 四、平均指数（PPT 第3节，常考变形）

**思路**：先算**个体指数** \(K_q=q_1/q_0\)、\(K_p=p_1/p_0\)，再对个体指数做**加权平均**得总指数。

### 1. 加权算术平均指数（数量指标常用）

\[
\bar{I}_q = \frac{\sum K_q \cdot p_0 q_0}{\sum p_0 q_0}
\]

**例题逻辑**（铅笔/围巾/帽子）：先算各商品 \(K_q\)，再以**基期销售额** \(p_0q_0\) 为权加权 → 得销售量平均指数。

### 2. 加权调和平均指数（质量/价格指标常用）

\[
\bar{I}_p = \frac{\sum p_1 q_1}{\sum K_p \cdot p_1 q_1}
\]

（或等价变形；记「价指常变形为调和平均」即可。）

### 3. 与综合指数的变形关系（必背口诀）

| 指数类型 | 宜变形为 | 常用权数 |
|----------|----------|----------|
| **数量指标** | **算术平均指数** | \(p_0q_0\) |
| **质量/价格指标** | **调和平均指数** | \(p_1q_1\) |

**仅当权数为 \(p_0q_0\) 或 \(p_1q_1\) 时**，平均指数与拉氏/派氏综合指数才有**一致变形**（才有实用意义）。

### 4. 课后 8.1 易考题

| 题眼 | 答案要点 |
|------|----------|
| 以**基期销售额**为权的加权平均**比率**价格指数 | **C** |
| 以**基期变量值**加权 | **拉氏 A** |
| 正常经济下 **拉氏 > 派氏** | **C** |
| 销售量**同比例**变动时，拉氏 104.5%、派氏 | **派氏=104.5% B**（量同比例则两指数相同） |
| 派氏 110% 时拉氏 | **一定 >110% C** |

### 5. 零售物价指数（了解）

编制要点：选代表规格品、地区与商店、采集价格、确定权数（各层零售额比重）→ 对个体或层类价格指数加权。

### 6. 马艾公式、理想指数（了解）

**理想指数** = 拉氏与派氏指数的**几何平均**（费雪指数）；大纲以拉氏/派氏/平均指数为主，理想指数认名即可。

## 五、指数体系与因素分析

**销售额体系**：

\[
\frac{\sum p_1 q_1}{\sum p_0 q_0} = \frac{\sum p_0 q_1}{\sum p_0 q_0} \times \frac{\sum p_1 q_1}{\sum p_0 q_1}
\]

（销售量指数 × 价格指数）

**差额分析**：总差额 = 数量变动影响 + 价格变动影响。

**易算**：

- 销售额增 1.5%、价格增 1.5% → 销售量**不变** D  
- 销量增、额不变 → 价格指数**下降** B  
- 销量不变、额不变 → 价格指数 **100%** C  
- 产值指数可能 **105%、110%** 等 DE

## 五（续）指数数列与基期更换（第5节核心，必考）

### 1. 指数数列是什么

把各期**总指数**按时间先后排列 → **指数数列**（动态数列的一种），反映总体变动过程与趋势。

### 2. 定基指数数列 vs 环比指数数列

| | 定基指数 | 环比指数 |
|---|----------|----------|
| 对比基准 | 固定**基期** \(0\) | **上一期** |
| 权数 | 可有**不变权数**或可变权数 | 通常**可变权数** |
| 关系 | 各期环比连乘 = 相应定基（与时间数列发展速度同理） | 相邻定基之比 = 环比 |

**产量指数数列**常用：**不变权数**的拉氏物量指数——选定某年基期价格 \(p_0\) 作「不变价格」，长期用拉氏公式编制。

### 3. 不变权数表（课件表 12.3，要会认）

| 指数类型（定基） | 可变权数 | 不变权数 | 指数类型（环比） | 可变权数 | 不变权数 |
|------------------|----------|----------|------------------|----------|----------|
| 拉氏价格指数 | | √ | 拉氏价格指数 | √ | |
| 拉氏数量指数 | | √ | 拉氏数量指数 | √ | |
| 派氏价格指数 | √ | | 派氏价格指数 | √ | |
| 派氏数量指数 | √ | | 派氏数量指数 | √ | |

口诀：**定基 + 拉氏数量 → 常不变权；环比 + 派氏价格 → 常可变权**（以课件表为准背勾）。

### 4. 基期更换与数列编接

- **基期更换**：不变价格用久了要换新的基年（现实价格结构变了）。
- **数列编接**：更换基期后，新旧指数不能直接比，要把旧序列**换算**到新基期，保证数列**延续可比**（课件强调「为了保证数列的延续，需要进行数列编接」——计算步骤以课堂例题/PPT 为准，考试按老师给的衔接公式做）。

**易混**：
- **指数调整**（缩减指数、不变价 GDP）≠ **基期更换**（换基年 + 编接）
- **定基价格指数不变权** → 课后题 **A**

## 六、指数调整与 CPI

- **指数调整**：剔除价格影响（A）  
- **实际工资** = 名义工资 ÷ **CPI**（C）  
- CPI **>100%**（如 101）→ 若不增工资，生活水平下降（D）  
- CPI 涨 20% → 1 元现值 ≈ \(1/1.2 \approx 0.83\) 元（D）  
- 少买 15% 商品 → 物价指数约 **117.6%**（A）  
- 不变价 GDP = 现价 GDP ÷ 缩减指数（108% → 2/1.08≈1.85 万亿 A）

**CPI 分类指数**：全国不是城市+农村简单相加（D 可能 98.9 等）。

## 先读：本章习题考点（易懂版）

### 单选（第八章课后 + 8.1）
- 指数公式「经济意义」：区分**价格变动**还是**销售量变动**引起的销售额差。销量变→销售额变，选 **销售量引起（D）**；价格变→选 C。
- **销量增、销售额不变**→单价必降→**销售价格指数减少（B）**。
- **以基期变量值加权**→**拉氏（A）**；报告期加权→派氏。
- **CPI>100%**（如 101%）→同样钱买不到原来那么多→生活水平**下降（D）**。
- 指数数列**不变权数**→常用**拉氏定基价格指数（A）**。
- **基期销售额为权**的加权平均**比率**价格指数→课件公式对应选项 **（C）**（记：价指常派氏、量指常拉氏，具体以选项为准）。
- **实际工资**=名义工资÷**居民消费价格指数 CPI（C）**。
- CPI 涨 20%→1 元购买力≈1/1.2≈**0.83 元（D）**；只能买 90% 商品→物价涨 1/0.9−1≈**11.11%（B）**。
- 正常情况：**拉氏指数 > 派氏指数（C）**（因权数固定在基期/报告期不同）。
- **平均指数口诀**：**量指→算术平均**（权 \(p_0q_0\)）；**价指→调和平均**（权 \(p_1q_1\)）。销量**同比例**变→拉氏=派氏（如都 104.5%）。

### 多选与计算
- **指数**能综合反映变动方向与水平，是宏观与民生指示器，常用 **%** 作单位 **ABCE**（D 错：不同事物不能硬用同一实物单位）。
- 设 q 销量、p 价格：销售量指数反映**多种商品销量综合变动（C）**，并反映销量变动对销售额的影响 **（E）**→常选 **CE**。
- **同度量因素**：在指数中起**权数**作用，并使不同度量单位可相加 **BE**。
- 指数**优良性**检验：**时间颠倒、因子颠倒、循环（ABE）**。
- 零售价格指数 110%→**总体上涨，可有涨有落（C）**。
- 销售量指数、工资水平指数的同度量因素：**单位商品销售价格、职工人数（D）**。
- 销量、价格各增 10%→销售额增 (1.1×1.1−1)=**21%（D）**。
- 销售额与价格**同增 1.5%**→销售量指数**不变（D）**（两者相除抵消）。
- 销量、销售额都不变→价格指数 **100%（C）**。
- **指数调整作用**：剔除**价格因素**对物量的干扰 **（A）**。
- 产值：产量、出厂价都涨→产值指数可 **>100%（DE）**。
- **减缩指数** 108%：不变价 GDP = 现价 GDP ÷ 1.08 ≈ **1.85 万亿（A）**。
- **道·琼斯**指数组成：**工业 30、运输 20、公用 6、综合 56 家（ABCD）**。

### CPI 与生活（8.3）
- 销售额指数=销售量指数×价格指数；同度量因素要同时起**权数+同度量**作用 **BE**。
