## 一、函数关系 vs 相关关系

| | 函数关系 | 相关关系 |
|---|----------|----------|
| 确定性 | \(y=f(x)\)，一一对应 | y 随 x 变但不唯一确定 |
| 图形 | 点在一条线上 | 点在直线/曲线**周围** |
| 课后定义 | 完全相关 = 函数 | 存在依存，**关系值不固定**（B） |

**相关关系特点**：有数量依存；不完全确定；x 给定 y 可有多个值。

---

## 二、相关类型（分类表）

| 划分标准 | 类型 |
|----------|------|
| 变量个数 | 单相关 / 复相关 |
| 形态 | 线性 / 非线性 |
| 方向 | 正 / 负 |
| 程度 | 完全相关、不完全相关、不相关（CDE） |

**易混**：函数关系是**完全相关**的特例（ACE）；独立 ⇒ 不线性相关，但可能非线性相关（ACE）。

**复相关**：三个及以上变量之间的相关（如 \(x_1,x_2\) 与 \(y\) 同时相关）；本课重点在**单相关 + 一元回归**，多元在 §六。

---

### 相关分析 vs 回归分析（PPT 区别，简答可用）

| | 相关分析 | 回归分析 |
|---|----------|----------|
| 变量地位 | x、y **平等** | **y 因变量**，x 自变量（用于解释/预测 y） |
| 随机性 | x、y 多视为**随机变量** | y 随机，x 常为**可控/非随机** |
| 回答的问题 | **有无**相关、**多强**、方向 | x 对 y **影响多大**、**预测** y |
| 工具 | r、散点图、t 检验 ρ | ŷ=a+bx、R²、**t 检 b**、**F 检方程** |

## 三、相关分析步骤

1. 有无相关  
2. 形式（线性还是曲线 → 定回归模型）  
3. 密切程度与方向  

工具：**相关表**、**散点图**。

**相关关系特点**（PPT 四条）：① 有数量依存 ② 关系**不固定** ③ x 给定 y 可不唯一 ④ 点分布在直线/曲线**周围**（不是落在一条线上）。

## 四、Pearson 相关系数 r（只衡量线性！）

**计算式**：

\[
r = \frac{n\sum xy - \sum x \sum y}{\sqrt{[n\sum x^2-(\sum x)^2][n\sum y^2-(\sum y)^2]}}
\]

**1234 记忆**：

| | 内容 |
|---|------|
| **1** 个范围 | \(r \in [-1,1]\) |
| **2** 个方向 | \(r<0\) 负相关，\(r>0\) 正相关 |
| **3** 个关键点 | \(r=\pm1\) 完全线性；\(r=0\) 无线性相关 |
| **4** 个程度 | \|r\|<0.3 微弱；0.3–0.5 低；0.5–0.8 显著；0.8–1 高度 |

**注意**：

- 与单位无关；对称  
- **不能**说明因果关系；警惕虚假相关  
- 是否相关要看**检验**，不能只看 r 大小（D）  
- r 的取值**不可能** 1.9（D）  
- 样本 r 是随机变量，随抽样变化（D）  
- 总体 \(\rho\) 用 R 估计（ADE）；样本 R 是 BCDE  

### 总体相关系数 ρ 的显著性检验（**t 检验**，PPT 第6节）

**目的**：检验两变量之间**是否存在线性相关**（不能只看 |r| 大小，题选 **D：要通过检验**）。

| 步骤 | 内容 |
|------|------|
| 1 | \(H_0:\rho=0\)（无线性相关）；\(H_1:\rho\neq 0\) |
| 2 | 计算 **t 统计量**（也叫 t 值） |

\[
t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} \sim t(n-2)
\]

| 3 | 给定显著性水平 \(\alpha\)（常用 0.05、0.01） |
| 4 | **决策**：\|t\| > \(t_{\alpha/2}(n-2)\) → **拒绝** \(H_0\)，认为存在线性相关；或看 **p 值**：**p < α** → 拒绝 |

**与课后题**：r=0.4 且检验**显著** → 可判**正相关（C）**；不能单凭 r>0.7、0.8、0.9 断定（A/B/C 错）。

## 五、一元线性回归

### 1. 模型

\[
y = a + bx + \varepsilon, \quad \hat{y} = a + bx
\]

### 2. 最小二乘法

使 \(\sum (y_i - \hat{y}_i)^2\) **最小**（D：实际值与估计值离差平方和最小）。

### 3. 参数估计（记法）

\[
b = \frac{L_{xy}}{L_{xx}}, \quad a = \bar{y} - b\bar{x}
\]

（\(L_{xy}=\sum(x_i-\bar{x})(y_i-\bar{y})\) 等）

**r 与 b**：符号一致；\(r = b \cdot \frac{\sigma_x}{\sigma_y}\)（概念）。

### 4. b 的经济含义（必考）

**x 变动 1 单位，y 平均变动 b 单位**（C）——不是总额、不是反向。

例：b=0.526 → 可支配收入每增 1 元，消费支出平均增 0.526 元。

### 5. 拟合优度

\[
R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}, \quad \text{一元时 } R^2 = r^2
\]

- \(R^2\) 越大拟合越好（B）  
- SSR = 回归平方和 = 受 x 解释的变差（BCE）  
- 例：SSR=4800，SSE=200 → \(R^2=4800/5000=0.96\)（C）

### 6. 估计标准误差

基于**残差平方和**；完全线性相关时 \(S_e=0\)（D）。  
|r|=1 时 \(R^2=1\)，\(S_e=0\)（ABD）。

### 7. 离差平方和分解（PPT 必背）

\[
\text{SST} = \text{SSR} + \text{SSE}
\]

| 符号 | 名称 | 含义 |
|------|------|------|
| **SST** | 总离差平方和 | \(\sum(y_i-\bar{y})^2\) |
| **SSR** | 回归平方和 | \(\sum(\hat{y}_i-\bar{y})^2\)，由 x 解释的变差 |
| **SSE** | 残差平方和 | \(\sum(y_i-\hat{y}_i)^2\)，随机误差 |

**可决系数**：\(R^2 = \text{SSR}/\text{SST} = 1 - \text{SSE}/\text{SST}\)；一元回归 **\(R^2=r^2\)**。

**估计标准误差 \(S_y\)**：残差平方和均方的平方根；越小拟合越好；完全相关时 **\(S_y=0\)**。

### 8. 模型检验：t 检验与 F 检验（PPT「模型评价」，必考）

课件把回归评价拆成：**拟合优度 \(R^2\)**、**估计标准误 \(S_y\)**、**系数 t 检验**、**方程 F 检验**。Excel「数据分析→回归」输出里常见 **t Stat**、**F Stat**（即 **F 统计量 / F 值**，有的材料写作 F score，指同一回事）。

#### 8.1 先记三个平方和（做 F 检验的基础）

\[
\text{SST}=\text{SSR}+\text{SSE}
\]

| 符号 | 自由度（一元） | 均方 MS |
|------|----------------|---------|
| SSR | 1 | MSR = SSR / 1 |
| SSE | **n−2**（课后 **A**） | MSE = SSE / (n−2) |
| SST | n−1 | — |

**估计标准误**：\(S_y=\sqrt{\text{MSE}}=\sqrt{\text{SSE}/(n-2)}\)（PPT：残差均方根；越小拟合越好；完全相关时 **\(S_y=0\)**）。

#### 8.2 一元回归 · **t 检验**（系数 b 是否显著）

| 项目 | 内容 |
|------|------|
| **检验对象** | 回归系数 **b**（斜率）：x 对 y 的**线性影响**是否显著 |
| **原假设** | \(H_0:\beta_1=0\)（x 与 y **无线性关系**） |
| **备择** | \(H_1:\beta_1\neq 0\) |
| **统计量** | \(t = \dfrac{b}{S_b}\)，其中 \(S_b = \dfrac{S_y}{\sqrt{L_{xx}}}\)，服从 **t(n−2)** |
| **决策** | **p < α** → 拒绝 \(H_0\)，认为 **b 显著**，x 与 y **存在线性关系**；p ≥ α → 不拒绝 |

**口诀**：**t 看斜率**——「x 变动 1 单位，y 是否真的跟着变」。

#### 8.3 一元回归 · **F 检验**（整条回归方程是否成立）

| 项目 | 内容 |
|------|------|
| **检验对象** | **整个一元线性回归方程**是否成立（PPT：模型是否显著） |
| **原假设** | \(H_0:\beta_1=0\)（方程无效，等价于一元只有截距） |
| **F 统计量（F 值）** | \(F = \dfrac{\text{MSR}}{\text{MSE}} = \dfrac{\text{SSR}/1}{\text{SSE}/(n-2)} \sim F(1,\,n-2)\) |
| **决策** | **p < α** → 拒绝 \(H_0\)，**回归方程显著** |

**一元重要关系**：在简单线性回归中，**F = t²(b)**（同一检验的两种形式）；因此「方程 F 检验」与「系数 t 检验」结论一致。

#### 8.4 多元回归 · **F 检验** vs **t 检验**（分工不同，课后常考）

| 检验 | 用在哪 | 原假设（典型） | 课后答案 |
|------|--------|----------------|----------|
| **F 检验** | **整个多元回归模型**是否显著 | \(H_0:\beta_1=\beta_2=\cdots=\beta_p=0\) | 第9题选 **C**；第41题选 **B**（能用 F，即方差分析） |
| **t 检验** | **某一个**自变量系数 \(\beta_j\) 是否显著 | \(H_0:\beta_j=0\) | 单个系数看 t，**不能**用 F 代替 |

**F 统计量（多元）**：

\[
F = \frac{\text{SSR}/p}{\text{SSE}/(n-p-1)} \sim F(p,\,n-p-1)
\]

- **SSR 自由度** = **p**（课后 **D**）  
- **SSE 自由度** = **n−p−1**  
- F 检验显著 → **至少有一个**自变量与 y 的线性关系显著（**A**），**不等于**全部显著（B 错）

**易混**：

| 说法 | 对错 |
|------|------|
| 多元整体显著用 **F 检验** | ✅ |
| 多元整体显著用 **t 检验** 代替 | ❌（t 用于单个 \(\beta_j\)） |
| F 显著 ⇒ 每个 x 都显著 | ❌ |
| 一元：F 检验与 t 检验（b）结论相同 | ✅（F=t²） |

#### 8.5 判断流程（做题用）

```text
相关分析：算 r → 对 ρ 做 t 检验（公式含 r、n）→ 能否说“相关”
一元回归：估 ŷ=a+bx → 看 R²、Sy → t 检验 b → F 检验方程（或看 F=t²）
多元回归：先 F 检验整体 → 再逐个 t 看 βj
```

**不相关时**：r=0、b=0、\(R^2=0\) 可同时出现，但**不一定独立**（ABCE）；无线性相关仍可能有**非线性**相关（ACE）。

### 9. 回归名词（了解）

**「回归」**：高尔顿研究父子身高——子代身高有向父辈**平均身高回归**的趋势（PPT 拓展）。

### 10. 计算例题

产量 1000、成本 30000、固定成本 6000 → \(Y=6000+24x\)（B）  
\(Y=85-5.6x\)（x 千件）→ 负相关；产量每增 1 千件成本平均**减** 5.6 元（ACE）  
可支配收入例：**b=0.526** → 收入每增 1 元，消费平均增 0.526 元；x=2000 → \(\hat{y}=2000×0.526-53.9=998.1\)

**预测**：只能由 x 推 \(\hat{y}\)，**不能**随意逆推 x（PPT：只能单向推算）。

### 11. 一元非线性回归（了解，PPT 拓展）

曲线关系先换元或选模型再线性化，常见类型：**双曲线、幂函数、指数曲线、对数曲线、抛物线**等（课件 P172 列表）。考试以**识别「非线性相关」**为主：r=0 或无线性相关时，仍可能有曲线相关（ACE）。

## 六、多元线性回归（提要）

- 两个及以上自变量（AD）  
- \(\beta_j\)：在**其他变量不变**时，\(x_j\) 增 1 单位 y 的平均变动（D）  
- **整体显著 → F 检验**（第9、41题 **C/B**）；**单个系数 → t 检验**  
- F 显著 ⇒ **至少一个** \(\beta_j\neq 0\)（第42题 **A**），不是全部显著  
- **SSR 自由度 = p**（D）；**SSE 自由度 = n−p−1**  
- 修正可决系数 \(\bar{R}^2\)（了解）：惩罚自变量过多（PPT 多元拟合优度）

## 先读：本章习题考点（易懂版）

### 相关 vs 回归（简答）
- **相关**：x、y 平等，看**有无/强弱**（r、t 检 ρ）。**回归**：y 因变量，看**影响与预测**（ŷ、t 检 b、F 检方程）。

### 相关
- **负相关定义**：x 增 y 减（**C**）。r 不可能 **1.9（D）**；是否相关要看**检验（D）**。
- **r=0.4 且显著**→正相关（C）。**收入与消费** r 约 **0.9（A）**。
- **样本 r** 随抽样变（D）；**独立**→不线性相关，可有非线性（**BCE/ACE**）。

### 相关 · t 检验（ρ）
- **是否相关看检验（D）**，不能只看 |r|>0.8/0.9。
- H0:ρ=0；**t = r√(n−2)/√(1−r²) ~ t(n−2)**；**p<α** 或 |t|>临界 → 有线性相关。
- r=0.4 且检验显著 → **正相关（C）**。

### 回归 · t 检验与 F 检验（=F 统计量/F 值/F Stat）
| 检验 | 对象 | 要点 |
|------|------|------|
| **t（b）** | 斜率 b 是否显著 | t=b/Sb，df=**n−2**；p<α → x 对 y 线性影响显著 |
| **F（方程）** | 整条一元方程是否成立 | **F=MSR/MSE=SSR/(SSE/(n−2))**；一元 **F=t²(b)** |
| **F（多元整体）** | 模型是否显著 | 第9题 **C**；第41题 **B**（方差分析）；F 显著→**至少一个** x 显著（**A**） |
| **t（多元单个）** | 某个 βj | 整体用 F，**单个系数用 t** |

- **SST=SSR+SSE**；SSE 自由度 **n−2（A）**；多元 SSR 自由度 **p（D）**。
- **R²=SSR/SST**；R²=0.81→r=**±0.9（B）**；SSR=4800,SSE=200→R²=**0.96（C）**。
- **b**：x 变 1 单位 y **平均**变 b（D）。**Sy=√MSE**。
- 产量例 **Y=6000+24x（B）**；βj **其他不变**时变动（D）。
