## 一、统计整理

**含义**：审核、分组、汇总 → 条理化、系统化 → 反映**总体特征**。  
**地位**：调查 ↓ **整理** ↓ 分析 的连接点。

**一般程序**（与第02章一致）：**审核** → **分组** → **汇总** → **制表** → **绘图**（ABCDE）

**审核**：准确性、完整性、及时性（ACE）

## 二、统计分组（核心）

### 1. 两层含义

- 总体 **「分」**：划分类别  
- 个体 **「合」**：同质单位归组  

结果：**组内同质，组间差异**（A）。

### 2. 原则

| 原则 | 要求 |
|------|------|
| **穷尽** | 每个单位都有组可归 |
| **互斥** | 只属于一组 |
| **反映本质** | 分组要能体现质的差异 |

### 3. 分类

| 划分 | 类型 | 说明 |
|------|------|------|
| 按标志**性质** | **品质标志分组** / **数量标志分组**（B） | 品质：在品质差异范围内定组界（性别、民族、文化程度）；数量：在数量差异范围内定组界（工龄、子女数） |
| 按标志**个数** | **简单分组** / **复合分组** | 简单：只按**一个**标志；复合：**两个及以上**标志**重叠**分组 |

**复合分组例题（存款）**：先按存款**性质**（企业/储蓄/财政），再在各性质内按**期限**（活期/定期）细分——形成「性质×期限」交叉结构（PPT 表）。

**分组对错例题**：

- 文化程度：应把「小学未毕业」并入低层次组，**不能**与「小学毕业」并列又互斥混乱（×）  
- 商场服装：只分男/女/童为**简单分组**（√）；再分成年装/儿童装为**复合**（× 若与前者混为一谈）

**分组关键**：**分组标志 + 分组界限**（D）；首先考虑**选什么标志**（B）。

### 4. 作用（PPT 三条，简答可用）

1. **划分现象类型**——研究不同类型特征  
2. **反映现象内部结构**——计算各组比重  
3. **研究现象间依存关系**——以一标志分组，观察另一标志变动（自变量分组看因变量）

## 三、次数分布（频数分布）

**概念**（PPT）：在分组基础上，把总体全部单位**按组归类**，按一定顺序排列，形成各单位数在各组间的分布；又称**频数分布**。  
（整理是调查→分析的**连接点**、分析的**前提**。）

- **频数 \(f\)**：各组单位数（次数）  
- **频率**：\(f / \sum f\)（各组比重，和为 1 或 100%）；频率 = 各组次数 ÷ 总次数（2.3 习题 D）

### 数列类型

| 类型 | 说明 |
|------|------|
| **品质分布数列** | 按品质标志分组 |
| **变量分布数列** | 按数量标志分组 |
| **单项数列** | 每个变量值一组；适用于**离散且取值较少**（C） |
| **组距数列** | 连续或取值多的变量 |

### 组距数列要点

- **组限**：连续变量相邻组限**必须重叠**（E）；离散可间断（D）
- **上组限不在内**（A）——落在组内统计
- **组中值**（代表组内一般水平）：假定组内**均匀分布**（D）
- **开口组中值**（必会算）：  
  - 末组下限 200、邻组中值 150 → 中值 **250**（B）  
  - 公式：末组中值 = 下限 + 邻组组距/2（邻组中值与下限差即为半组距）

### 累计频数

| 类型 | 又称 | 含义 |
|------|------|------|
| **向上累计** | 较小累计 | **小于**某组上限的次数/频率（AC） |
| **向下累计** | 较大累计 | **大于等于**某组下限的次数（BD） |

**课件例题（50 个商店销售额）**：等距分组后除频数、频率外，应会填**向上累计**、**向下累计**两列（较小制 / 较大制），用于后面求中位数、四分位。

### 组距数列编制步骤（等距，必会流程）

1. **排序**，求 \(R=\text{最大值}-\text{最小值}\)（全距）
2. 定**组数 \(K\)** 与**组距 \(d\)**：\(R \leq d \times K\)；\(d=\) 全距 \(/K\)，宜取 2、5、10 的倍数  
   - **Sturges 经验公式**（\(n\) 为单位数，\(K\) 向上取整）：  
     \[
     K = 1 + \frac{\ln n}{\ln 2} \quad \text{或} \quad K \approx 1 + 3.322\lg n
     \]
3. 定**组限**：连续变量相邻组**重叠**、**上组限不在内**；可设开口组「××以下」「××以上」  
4. 汇总各组 **\(f\)**、频率，必要时做双向累计

### 单项数列编制

- 条件：离散变量、**取值种类少**（如看管机器 1–4 台，20 人）  
- 步骤：排序 → 计各值频数、频率 → 列表

### 频数分布类型（识图）

| 类型 | 形态 | 例子 |
|------|------|------|
| **对称（正态）** | 中间多、两边少 | 身高、成绩 |
| **右偏（正偏）** | 长尾在右 | 收入 |
| **左偏（负偏）** | 长尾在左 | — |
| **U 型** | 中间少、两头多 | 人口死亡率 |
| **J 型** | 正 J（供给）、反 J（需求） | 价格—数量 |

**次数密度**（异距分组）：\(=\) 频数 \(/\) 组距，用于比较不同组距组的次数集中程度（工人年龄例题）。

## 四、统计表

### 结构（形式四部分）

**总标题**、**横行标题**、**纵栏标题**、**数字资料**（D）。另有表头、表体、表脚（填表人、日期、说明）。

### 设计规则

- 简明扼要、便于阅读；数字**右对齐**、文字左对齐（惯例）  
- 各栏计量单位**一致**时，单位标在表**右上角**（C）  
- 缺项用「—」；同一表内层次清楚

### 类型

| 类型 | 说明 |
|------|------|
| **简单表** | 不分组，总体或项目罗列 |
| **简单分组表** | 按一个标志分组 |
| **复合分组表** | 两个及以上标志交叉分组（ACE） |

## 五、统计图怎么选（必考）

| 目的 | 图 |
|------|-----|
| 长期趋势（多年 GDP） | **折线图** D |
| 结构占比（三次产业） | **饼图** C |
| 分类对比 | 条形图、饼图 CD |
| 分布形态、分组资料 | **直方图**、茎叶图、箱图 AE |
| 两变量关系 | **散点图** |
| 均价分布（房价） | **直方图** A |
| 两年三省产业结构变化 | **六张饼图** D |
| 法人单位按组织形式分布 | **条形图 + 饼图**（CD） |
| 抽样调查结构（各区户数） | **条形图、饼图**（AC） |
| 按月消费额分组看分布 | **直方图、箱图、茎叶图**（AE） |

**易混**：

- **折线图**：**一个变量随时间**变化（GDP 50 年趋势）  
- **散点图**：**两个变量**相关关系（人均 GDP vs 人均消费）——第3章习题第2题选散点，不是折线  
- **饼图**：**结构比重**（三次产业、类别占比）  
- **条形图**：**分类对比**（可多系列）

**完整统计图**：标题、坐标轴和网格线、图表区、绘图区、图例（ABCDE）。

### 直方图

- **等距分组**：用柱形**高度**表示次数（A）  
- **异距分组**：用柱形**面积**；纵轴常用**频率密度**（A）  
- 与条形图区别：直方图用于**连续型/组距**分布，条间**无间隙**（或组距概念）

### 其他图（识名）

| 图 | 用途 |
|----|------|
| **茎叶图** | 保留原始数据的分布形态 |
| **箱线图** | 中位数、四分位、离群点 |
| **散点图** | 两变量相关（第8章） |
