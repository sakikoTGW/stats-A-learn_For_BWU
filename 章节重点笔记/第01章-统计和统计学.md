## 一、统计的三种含义（必考）

| 含义 | 是什么 |
|------|--------|
| **统计工作** | 为认识与管理需要，对社会经济/自然现象做**数量收集**的活动 |
| **统计资料** | 统计工作中得到的数字资料及附带信息 |
| **统计学** | 收集、整理、**描述**、**分析**数据的方法科学，探索数量规律 |

**统计学的数据流程**（与「统计工作环节」对应）：

收集 → 整理 → 描述（图表）→ 分析 → **科学认识**

**统计工作五环节**（顺序题高频）：

\[
\text{设计} \to \text{调查} \to \text{整理} \to \text{分析} \to \text{应用}
\]

---

## 二、描述统计 vs 推断统计

| | 描述统计 | 推断统计 |
|---|----------|----------|
| **干什么** | 取得数据，加工、显示、概括分布 | 由**样本**推断**总体** |
| **主要内容** | 收集、整理、显示、分布特征 | **参数估计**、**假设检验** |
| **关系** | 基础、前提 | 发展、核心（现代统计以样本为主） |

- **推断统计学研究什么** → 如何根据样本推断总体数量特征（D）
- **描述统计包括什么** → 收集、加工、显示、分布概括（ABCD），**不含**抽样推断（E 错）

**按构成划分**：描述统计学 + 推断统计学（A）  
**按研究与应用程度**：理论统计学 + 应用统计学（AC）——不是「描述+推断」那种分法混为一谈。

### 理论统计学 vs 应用统计学（PPT）

| | 理论统计学 | 应用统计学 |
|---|------------|------------|
| 内容 | 统计学**基本理论、原理、方法**；广泛采用数理统计 | 从具体问题出发，选用适当统计方法 |
| 地位 | 统计方法的**理论基础** | 在经济、生物、管理等领域**具体应用** |

**描述与推断的关系**（简答常考）：

- 描述统计是推断统计的**前提**；推断统计是描述统计的**发展**  
- 两者**相互联系、相互依存**；现代统计以**样本**为主，推断统计是核心标志  
- 没有可靠的描述统计与样本信息，推断方法也得不出科学结论  
- **看数据，从描述统计做起**

### 统计学应用领域（了解，PPT）

经济统计、金融、管理、人口（**第六、七次人口普查**）、教育、生态、气象、物流、生物统计、遗传统计等。

## 三、学派与人物（选择题送分）

| 学派 | 评价 | 人物 |
|------|------|------|
| **国势学派** | 有**统计学之名，无统计学之实** | 康令、阿亨瓦尔（德国） |
| **政治算术学派** | 有**实无名**，真正起源；配第「**政治经济学之父**」 | 威廉·配第、约翰·格朗特（英国） |
| **数理统计学派** | 统计与概率结合；凯特勒 | 比利时 |
| **社会统计学派** | 全面调查为主，可适量抽样 | 克尼斯、恩格尔、梅尔 |

课件题：统计涵义 ACE（工作、资料、统计学）；政治算术 CE（配第、格朗特）；国势学派 D；马克思称政治经济学之父 → **配第 C**。

### 统计学发展三时期（PPT 第二节）

| 时期 | 内容 |
|------|------|
| **萌芽期** | 国势学派（有名无实）；政治算术学派（有实无名，真正起源） |
| **近代期** | 数理统计学派；社会统计学派 |
| **现代期** | 社会经济统计 + 数理统计两大分支并行 |

**应用统计学**：各分支（经济、生物、社会…）方法基础相同（描述+推断），领域各有特色（如经济统计中的**时间序列、统计指数**）。

### 统计学现代格局（PPT 末）

统计学广泛应用于：**经济、社会、生物、工业、物流**等领域；本课程以经济与管理现象为主。

**近代著名统计学家**（了解）：伯努利、棣莫弗、贝叶斯、高斯、皮尔逊、**费希尔**、奈曼等——与数理统计、假设检验发展相关。

### 案例：统计工作五环节（智能快递柜）

目的 → **收集**（问卷）→ **整理**（分组）→ **描述**（表图）→ **分析**（回归、信度效度）→ **认识**（改进设计）。与「收集→整理→描述→分析→科学认识」一致。

## 四、数据的计量尺度（由低到高）

\[
\text{定类} \to \text{定序} \to \text{定距} \to \text{定比}
\]

| 尺度 | 例子 | 能否加减乘除 |
|------|------|----------------|
| **定类** | 性别、民族、籍贯 | 不能 |
| **定序** | 优/良/中/及格、满意度等级 | 可排序，间隔不一定相等 |
| **定距** | 温度（摄氏）、年份差 | 可减，无绝对零点 |
| **定比** | **年龄**、身高、收入 | 有绝对零点，可比值 |

- **定性数据（品质数据）** = 分类数据 + 顺序数据（A）
- 性别 → **分类**；优/良/中、非常满意…不满意 → **顺序**（BD）
- **年龄** → 定比（B）

**时间序列**：同一指标按时间排列（如历年 GDP、历年人口）→ AB；某年**各地区**人口是**截面**数据。

### 按结构划分（1.2 习题）

| 类型 | 含义 | 例子 |
|------|------|------|
| **截面数据** | 同一时点、不同单位 | 2003 年各地区人口、各地区 GDP |
| **时间序列** | 同一对象、不同时点 | 1952–2006 年历年人口、历年 GDP |
| **面板数据** | 多个对象 × 多个时点 | 各省多年指标（课件拓展） |

**定性数据** = 分类 + 顺序（品质数据）；**定量** = 定距 + 定比（数值型）。

**定距 vs 定比**：摄氏温度可减不可比倍数；年龄、身高、收入有绝对零点 → **定比**。

### 认识数据（大纲 §1.3，PPT 第三节要点）

| 划分 | 类型 | 说明 |
|------|------|------|
| 按计量 | **品质（定性）** | 定类 + 定序 |
| | **数量（定量）** | 定距 + 定比 |
| 按变量 | **离散型** | 整数、可数（人数、台数） |
| | **连续型** | 可取区间任意值（产量、面积）；年龄属连续但常按离散处理 |
| 按结构 | 截面 / 时间序列 / 面板 | 见上表 |

**不能**对定类、定序数据求算术平均（第5章）；定类只能用众数等。

## 五、总体论基本概念（最易混）

| 概念 | 定义 | 例题锚点 |
|------|------|----------|
| **总体** | 研究对象全体，**同质**单位组成；可分有限/无限总体 | 10 个企业职工工资调查 → 总体是 **10 个企业职工**（C），不是企业、不是工资总额 |
| **同质性** | 总体单位在某方面**共同属性**；研究工资则都是「职工」 | 换研究目的，总体可重新定义 |
| **总体单位（个体）** | 构成总体的基本单位 | 未安装设备普查 → 单位是 **每一台设备**（B） |
| **样本** | 从总体抽取、代表总体的部分 | 从总体抽取的集合体（A） |
| **标志** | 单位特征的名称（个体层面） | 产品等级、性别 → **品质标志**（A） |
| **标志值** | 标志的具体表现 | 80 分、85 分 → **标志值**（D），不是指标 |
| **指标** | **总体**的数量特征 | 平均工资、人口密度 → 指标在总体层面（D） |

**指标 vs 标志**：研究目的不同可**互相转化**（ABD），不是任何情况都能对调（E 错）。

**数量指标 vs 质量指标**（相对数、率、密度、人均类多为**质量指标**）：

- 出勤率、人口密度、平均工资 → **BC**
- 产量、销售额、合格品数量 → 数量指标

**五个指标里数量指标个数**：废品量、流通费用额 → **二个**（B）

## 六、变量

- **变量**：说明数量特征的**概念**（A）
- **变量值**：具体数值（考试成绩 80、85、92）
- **年龄**：连续变量，实践中常按离散处理（D）
- **机床产量（台）**：离散；**产值（元）**：连续（D）
- **连续型**：钢铁产量、图书馆面积（BD）
- **离散型**：人数、设备台数、藏书册数、站点数（ABCE）

**0-1 标志（是非标志）**：又称交替标志、0-1 标志（ABD）；用于成数、方差 \(p(1-p)\)。

---

## 七、认识路径与软件

- 统计对总体数量特征的认识：**从个体到总体**（C），不是反过来的。
- 指标体系：一系列相互联系、相互制约的指标（B）
- 指标特点：可量性、大量性、综合性、具体性（ABCE）
- 常用软件：SAS、SPSS、Stata（ACD）；Excel：**函数、公式、数据分析工具**（ABE）

### 统计计算工具（PPT 第五节）

| 途径 | 用途 |
|------|------|
| **函数** | AVERAGE、STDEV、COUNTIF… |
| **公式** | 单元格运算 |
| **数据分析工具** | 描述统计、直方图、回归、抽样 |

上机以 **Excel** 为主；R 在分组、回归拓展中出现。

## 先读：本章习题考点（易懂版）

> 下面按**考点**写清逻辑；文末「习题逐题」与 `_提取全文` 答案一致。正文对应：§一～§七。

### 统计学与统计工作
- **统计三含义**：统计**工作**（搞调查）、统计**资料**（数字结果）、**统计学**（方法）。题选 **ABC**，不含「统计局」。
- **描述 vs 推断**：描述=收集、整理、显示、概括分布（**ABCD**）；推断=用样本推总体（**D**），**不含**「抽样推断」放进描述统计（E 错）。
- **两种分科别混**：按方法构成→描述+推断（A）；按研究层次→**理论+应用（AC）**，不是 AC 和 BD 对调。
- **应用统计学**：生物、农业、卫生、社会、人口等 **ABCDE** 都是。

### 学派与人物
- **国势学派**：有名无实（D）。**政治算术**：配第、格朗特（**CE**），真正起源。
- **认识路径**：从**个体**汇总到**总体**（C），不是反着来。

### 数据类型（1.2）
- **尺度从低到高**：定类→定序→定距→定比（**A**）。**年龄**是定比（有绝对零点）。
- **分类数据**：性别、籍贯；**顺序数据**：优/良/中、满意度等级（**BD**）。学号在题里**不**选为顺序数据。
- **品质数据** = 分类 + 顺序（A）。**时间序列**：同一指标历年（AB）；各地区同年是**截面**。

### 总体论（1.3 + 课后）
- **总体**：研究对象全体。10 个企业职工工资调查→总体是**全部职工（C）**，不是企业、不是工资总额。
- **总体单位**：构成总体的个体。未安装设备普查→**每一台设备（B）**；50 人学习情况→**每一个学生（C）**。
- **样本**：从总体抽出的部分（A）。
- **标志**：单位身上的特征名（等级、性别）；**标志值**：80 分、85 分（D）；**指标**：总体的数量特征（D）。
- **品质标志**：等级、性别（A）。**数量指标**（绝对量）：产量、销售额、**废品量、流通费用额**→五个里**二个（B）**。
- **质量指标**（相对/率/平均/密度）：人口密度、平均工资；1.3 题选 **BC**；课后题把**出勤率**也算质量→**BCDE**。
- **指标↔标志**：换研究目的可互换（**ABD**），不能任何时候都对调（E 错）。
- **0-1 标志**：交替标志（ABD）；成数方差最大 **0.25**。

### 变量
- **变量**是概念（A），不是指标本身。**年龄**：连续变量，实务常当离散处理（D）。
- **产量（台）**离散，**产值（元）**连续（D）。连续：**钢铁产量、图书馆面积（BD）**。离散：**人数、设备台数、藏书册数、站点数（ABCE）**。

### 软件
- **SAS、SPSS、Stata（ACD）**。Excel：**函数、公式、数据分析工具（ABE）**，不是「过程」「方程」当主途径。

### 课后作业·第一章

**1.** 推断统计学研究（ ）。 A．统计数据收集的方法 B．数据加工处理的方法 C．统计数据显示的方法 D．如何根据样本数据去推断总体数量特征的方法
- **答案**：D
- **怎么理解**：推断统计：由样本推断总体参数（参数估计、假设检验） 样本：从总体抽取、代表总体的部分
- **正文位置**：见本章「先读：习题考点」+ 上文公式/表格小节

**2.** 在统计史上被认为有统计学之名而无统计学之实的学派是（ ）。 A．数理统计学派 B．政治算术学派 C．社会统计学派 D．国势学派
- **答案**：D
- **怎么理解**：国势学派：有统计学之名无统计学之实
- **正文位置**：见本章「先读：习题考点」+ 上文公式/表格小节

**3.** 下列数据中哪个是定比尺度衡量的数据（ ）。 A．性别 B．年龄 C．籍贯 D．民族
- **答案**：B
- **怎么理解**：定比尺度：有绝对零点，可加减乘除、可比倍数。年龄是定比，性别/籍贯是定类。 分类（定类）数据：性别、籍贯等，只能计数分类，不能比大小。
- **正文位置**：见本章「先读：习题考点」+ 上文公式/表格小节

**4.** 统计对总体数量特征的认识是（ ）。 A．从定性到定量 B．从定量到定性 C．从个体到总体 D．从总体到个体
- **答案**：C

**21.** 数据的计量尺度由低到高,由粗到精可以分为 A：定类尺度、定序尺度、定距尺度、定比尺度 B：定比尺度、定距尺度、定序尺度、定类尺度 C：定序尺度、定类尺度、定距尺度、定比尺度 D：定类尺度、定序尺度、定比尺度、定距尺度
