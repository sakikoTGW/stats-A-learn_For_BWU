每章笔记**文末**有 **「配套课件（逐页图示）」**，已导出为 PNG 嵌在 Markdown 里。

1. 用 Cursor / VS Code 打开对应 `第XX章-….md`

3. 上半部分是复习笔记，下半部分按页显示课件，**无需再打开 pptx/pdf**
