## 五、计算与分析题（共45分）

**1.** 答案：`p=0.85；μ≈0.0252；（0.8006，0.8994）`

解析：p=170/200；μ=√[p(1−p)/n]；p±z·μ。

评分要点：（1）p 3分；（2）μ 4分；（3）区间与解释 8分。

知识点：kp7-10、kp7-2


**2.** 答案：`t=2；不拒绝H₀`

解析：t=(102−100)/(5/5)=2<2.064；|t|<临界值。

评分要点：（1）t 5分；（2）结论 5分；（3）α、β 5分。

知识点：kp7-5、kp7-9


**3.** 答案：`r=1；ŷ=1+2x；R²=1`

解析：完全正相关；b=2,a=1；R²=r²=1。

评分要点：（1）r 5分；（2）方程 6分；（3）R² 4分。

知识点：kp8-2、kp8-3、kp8-4
