| 说法 | 是否成立 |

| 知识点树图 | **是** — 每章「左→右知识导图」+ `全书知识点树图.md` |
| 第7–10章 + 细点 | **已接入**（样本、V_AD、平均指数、α/β、增长1%绝对值等已单列 KP） |
| 题库总量 | 约 **290+** 道；**每 KP ≥2 题**；不等于习题精讲逐题覆盖 |
| 挖漏审计 | `章节重点笔记/挖漏对照清单.md` |

## 题库

- 内置题约 **290+** 道（核心 + 课后题 + `supplementQuestions`）。
- **129 个知识点均有 ≥2 道题**。
- 维护补全题：`npm run gen:supplement`（读取零题/单题 KP，重写 `supplementQuestions.ts`）。
- 加题请手写 `homeworkQuestions.ts`，对照笔记 ⚠️ 行与「先读」考点优先。
- **不等于**笔记「习题逐题精讲」每一道都有对应选择题。
